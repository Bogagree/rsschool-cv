# CV cross-check (RS School)

When reviewing other students’ CVs, check **contrast**. Flag it in chat so the user can verify visually.

## Dark on dark

Look for:

- Black or near-black icons, logos, borders, or text on a black or very dark background
- Dark gray on dark gray (footer, header, cards, code blocks)
- RS School logo: a **black** SVG/PNG on a **dark** footer is a typical miss

If contrast is poor:

- Tell the user **what** is hard to see and **where** (e.g. “black RS School logo on a dark footer”)
- Ask them to confirm in the browser
- Deduct on **CSS** (not Footer, if the logo and school link are still present)
- Mention it in the review comment: use a light logo / lighter icon / higher contrast

Do **not** deduct for W3C **Info** about `/>` on void tags. Green “No errors or warnings” is valid.

Do **not** Submit the RS App form unless the user asks.
